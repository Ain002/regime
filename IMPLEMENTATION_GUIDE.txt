========================================
ÉTAPES D'IMPLÉMENTATION :
========================================

1️⃣  AJOUTER LES ROUTES
   - Ouvrir : app/Config/Routes.php
   - Copier tout le contenu du fichier ROUTES_TO_ADD.txt
   - Coller avant la dernière ligne de route

2️⃣  EXÉCUTER LES MIGRATIONS SQL
   - Ouvrir votre phpMyAdmin ou client SQL (ex: HeidiSQL, DBeaver, DataGrip)
   - Copier le contenu de SQL_TO_RUN.txt
   - Exécuter chaque requête CREATE TABLE
   - Optionnel : exécuter les INSERT pour données d'exemple

3️⃣  TESTER LES FONCTIONNALITÉS

   a) RÉGIMES :
      - Accédez à http://localhost:8080/regime
      - Cliquez "Ajouter un régime"
      - Remplissez : Nom, Durée, Variation poids
      - Assignez des aliments avec pourcentages (somme = 100%)
      - Soumettez et vérifiez affichage dans la liste
      - Testez Edit et Delete

   b) ACTIVITÉS SPORTIVES :
      - Accédez à http://localhost:8080/activity
      - Créez une activité (Nom, MET, Description)
      - Testez Edit et Delete

   c) CODES PORTE-MONNAIE (USER) :
      - Accédez à http://localhost:8080/wallet/request
      - Entrez un code (ex: CODE2024-001)
      - Soumettez (si session user_id existe)
      - Status passe à "pending"

   d) CODES PORTE-MONNAIE (ADMIN) :
      - Accédez à http://localhost:8080/admin/wallet
      - Voir les demandes en attente
      - Approuver ou rejeter
      - Marquer comme utilisé

   e) PARAMÈTRES :
      - Accédez à http://localhost:8080/parameter
      - Voir les clé-valeur
      - Cliquez Edit pour modifier un paramètre

========================================
⚠️  POINTS IMPORTANTS :
========================================

✅ BASE DE DONNÉES : NON MODIFIÉE (vous exécutez le SQL vous-même)

✅ SESSION USER : 
   - Le code WalletCodeController utilise session()->get('user_id')
   - Adaptez selon votre système d'auth (Auth0, Joomla!, custom, etc.)

✅ VALIDATION :
   - Somme des pourcentages = 100% (validée côté serveur)
   - Récatage des durées/montants en int/float

✅ SÉCURITÉ :
   - CSRF token sur tous les formulaires
   - esc() sur affichages dynamiques (prévention XSS)
   - Suppression via POST+confirmation (prévention accidentelle)

✅ REDIRECTIONS :
   - Toutes les redirections pointent vers /regime, /activity, /parameter (singulier)
   - Adaptez si vous préférez /regimes, /activities (pluriel)

✅ ROUTES RESOURCE ALTERNATIVE :
   - Si vous préférez utiliser CodeIgniter resource routes :
     $routes->resource('regime','RegimeController');
     $routes->resource('activity','ActivityController');
     (Mais vérifiez que les noms/méthodes correspondent)
