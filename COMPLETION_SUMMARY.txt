✅ 2. PRIX DYNAMIQUE SELON DURÉE + OPTION GOLD

   Schema SQL:
   • regime.prix_base   → Prix par semaine
   • regime.prix_gold   → Prix avec -15%
   
   Logique:
   • Prix = prix_base × durée
   • Prix Gold = Prix × 0.85
   
   Model: RegimeModel.php
   • calculatePrice($base, $duree, $hasGold)
     → ['price' => 100, 'price_gold' => 85, 'reduction' => 15]
   
   Helper: PriceHelper.php (5 fonctions)
   • calculateRegimePrice()     → Calcul complet
   • formatPrice()              → Format EUR
   • getPriceDisplay()          → Badge HTML
   • validateComposition()      → Validation 100%
   • getCompositionChartData()  → Data Charts
